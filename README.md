# شاشة أسعار — موبايل وتلفزيون

شاشة مستقلة للمحل. **لا تحتاج كمبيوتر ولا MetaTrader.**

الذهب والفضة: **دولار أمريكي لكل أونصة تروي**. اليورو: **دولار لكل يورو**.

## رابط مباشر (تلفزيون / موبايل)

https://georgebahna57.github.io/shasha-asear/

1. افتح الرابط على التلفزيون أو الجوال (Wi‑Fi).
2. اضغط **ملء الشاشة** (أو F11 على التلفزيون).
3. من الإعدادات اختر حجم الشاشة: **TV 32 / 41 / 50 inch**.
4. تحت **LIVE** يظهر التحديث كل أجزاء الثانية (أونصة مباشرة).

الشراء والبيع في المحل = سعر السوق ± الفرق الذي تضبطه في **Settings**.

## أندرويد (APK)

https://github.com/Georgebahna57/shasha-asear/raw/main/ShashaAsear-debug.apk

التطبيق يفتح نفس الرابط أونلاين — أي تحديث على الموقع يصل للتطبيق تلقائياً.

**بدون APK:** Chrome → الرابط → **Add to Home screen**.

## دقة 100% — MetaTrader 5 (مُوصى للمحل)

1. على **جهاز واحد** بالمحل: MT5 مفتوح + مؤشر `ShopPriceBridge` على الشارت + `start-board.bat`.
2. مرة واحدة كـ Administrator: `enable-lan-board.bat` (ليفتح على Wi‑Fi).
3. على **التلفزيون أو الجوال** (نفس Wi‑Fi): افتح **`http://عنوان-الجهاز:8765/`** — ليس رابط GitHub.
4. في الإعدادات: **MT5 فقط** مفعّل — السعر = نفس تيك **XAUUSD** في المنصة.

رابط GitHub / TradingView للمعاينة فقط — قد يفرق عدة دولارات عن وسيطك.

## تحديث لحظي (بدون MT5)

- **TradingView** احتياط — ليس بديلاً عن الوسيط.
- على التلفزيون: **ملء الشاشة** يفعّل إبقاء الشاشة مضاءة (Wake Lock) حيث يدعم المتصفح.

## ويندوز (اختياري — فقط لفتح الرابط كتطبيق)

`install-app.bat` يضيف أيقونة تفتح الموقع في نافذة Edge — **بدون** سيرفر محلي.

## للمطورين

```bash
npm install
npm run web          # نسخ الملفات إلى www/
npm run android:apk  # يتطلب Android SDK
```

## ملاحظة

السعر المعروض هو **سوق عالمي مجاني**، وقد يختلف قليلاً عن وسيط معيّن. للموبايل والتلفزيون هذا هو الوضع الطبيعي بدون PC.
